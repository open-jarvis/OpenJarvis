# OpenJarvis Project Scope

OpenJarvis is a framework for local-first personal AI.

Core owns shared behavior, interfaces, and support for models, engines, and hardware. Core maintainers own the framework implementation, quality, security, and compatibility.

Extensions own application-specific tools, integrations, configurations, and products. Extension maintainers own their dependencies, releases, security fixes, support, and supported OpenJarvis versions.

Core consists of:

* The five primitives: Intelligence, Engine, Agentic Logic, Tools, and Learning
* Security, research infrastructure, the API/SDK, extension interfaces, and a thin reference CLI
* The runtime that connects the above
