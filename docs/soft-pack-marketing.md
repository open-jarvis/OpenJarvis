# فريق ميديا سوفت باك

خمسة وكلاء في فريق «سوفت باك» يعملون كنقطة واحدة: تكلّم الفريق، فيوزّع المنسّق العمل، وتستلم الصورة النهائية في صفحة الطلب لتراجعها وتنزّلها بنفسك.

| الوكيل | القالب | الأدوات |
|---|---|---|
| منسّق الفريق | `softpack_orchestrator` | `team_assign_tasks`، `campaign_files` |
| التخطيط والكتابة | `softpack_planning` | `think` |
| الصور والتصميم | `softpack_production` | `marketing_creative` + أدوات MCP من اتصالات الفريق |
| مراجعة الجودة | `softpack_quality` | `think` |
| التسليم النهائي | `softpack_release` | `think` |

## الإعداد مرة واحدة

1. من **الوكلاء** اختر الفريق ← **الإعدادات والاتصالات** (صفحة الفريق `/agents/teams/<الفريق>/settings`) ← اختر «منسّق الفريق».
2. في «اتصالات الفريق» اضغط **+ إضافة اتصال** وأدخل بيانات خادم MCP عبر HTTP بحساب الشركة: الاسم، والعنوان، وطريقة المصادقة (Bearer أو ترويسة مخصصة تكتب اسمها، أو بدون)، والمفتاح. يُحفظ الاتصال ويُختبر فورًا، وبعد الاختبار تظهر أدواته، ويمكنك قصره على وكلاء محددين (مثل الصور والتصميم). خدمة معالجة الصور تُضاف بهذه الطريقة مثل أي MCP آخر.

حفظ الإعداد ليس دليلًا على نجاح المصادقة: الحالة «Verified» تظهر فقط بعد طلب ناجح فعلي.

## تشغيل طلب

افتح **صفحة الفريق والطلبات** ← **طلب جديد للفريق** ← اكتب الطلب، وارفع صور المنتجات الأصلية والشعار، وأدخل بيانات التواصل المعتمدة كما ستظهر على التصميم.

1. يستلم المنسّق الطلب تلقائيًا ويوزّع المهام. كل مهمة تشغّل الوكيل المستلِم تلقائيًا، وترجع نتيجته للمنسّق.
2. الصور والتصميم: يستخدم أدوات اتصالات الفريق المسموحة له. يمرّر الوكيل الصورة كمسار `campaign:originals/...` فيرسل الخادم الملف نفسه دون أن يمر عبر الموديل، والصور التي تُرجعها الخدمة تُحفظ تلقائيًا في `drafts/` ويبقى الأصل كما هو. ثم `marketing_creative` يركّب العنوان والشعار وبيانات التواصل بتخطيط ثابت (لا يولّد نصوصًا بالذكاء الاصطناعي) ويصدّر PNG بمقاس 1080×1080 عبر Chrome. إذا لم يتسع النص يفشل التصدير برسالة واضحة بدل قصّه.
3. المراجعة، ثم وكيل التسليم النهائي يجهّز الحزمة: مسار الصورة النهائية ونص المنشور والموعد المقترح بتوقيت القاهرة وملخص المراجعة.
4. لكل طلب صفحة خاصة به (تفتح من قائمة طلبات الفريق). في أعلاها قسم «الصور النهائية» يعرض كل صورة في `final/` بحجم كبير مع زر **تنزيل PNG**، وتجد النص والموعد ونتيجة المراجعة في تقارير سير العمل. لطلب تعديل اكتب للفريق في نفس الصفحة.

## الحدود

- أي جزء أعادت خدمة خارجية بناءه يحتاج مقارنتك بالأصل؛ لا يُعتبر مطابقًا تلقائيًا.
- وكيل المراجعة يعمل بالنص؛ إذا تعذّرت المعاينة البصرية يذكر ذلك صراحة، والحكم البصري لك عند مراجعة الصورة.
- الوكيل الموقوف لا يُستأنف تلقائيًا؛ مهامه تنتظر حتى تستأنفه.
